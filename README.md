# Consilium print library: STEP files

These are STEP (`.step`) versions of the printable designs in the Consilium Aegis print library by Satis Omnibus Limited. The same STL and OpenSCAD sources are free downloads on each product page at satisomnibus.com/consilium/print-library.

- **Format:** faceted solids converted from the STLs, one face per mesh facet, with coplanar faces merged where the solid stays valid. Use them for quoting, DFM and fit checks. Rebuild clean B-rep before making any tooling.
- **Contents:** each zip's `README.txt` lists its parts, the source STL and `.scad` hashes, and solid vs mesh volume. A few parts have sliver faces the B-rep checker flags; their README says so.
- **Licence:** [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), the same as the site's downloads.
- **Status:** prototype designs. Nothing here is tested or certified, and there are no IP, MIL or radio approvals.

Release `consilium-step-v1`: 85 zips (print and mould variants).
